# BooyahCoach Arena

Build the BooyahCoach mobile-first dark-mode web application exactly as requested: Free Fire and Free Fire MAX coaching marketplace, aggressive charcoal/crimson/gold theme, responsive header with language/profile/login controls, hero with stats and CTAs, coach search/filter bar, verified coach directory cards, four specialized coaching categories, and footer links. Use polished realistic demo data and visuals appropriate to the game-inspired product, without relying on copyrighted game assets.
